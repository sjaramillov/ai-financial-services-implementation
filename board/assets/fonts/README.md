# Local typography

These unmodified WOFF2 fonts are bundled for offline use. Each font is distributed under the SIL Open Font License 1.1; the original copyright statements and complete license texts are in [FONT-LICENSES.txt](FONT-LICENSES.txt).

| Family | Role | Included weights | Project or author |
| --- | --- | --- | --- |
| Bricolage Grotesque | Headings | Variable, 500–800 | https://github.com/ateliertriay/bricolage |
| Atkinson Hyperlegible | Body text | 400 and 700 | Braille Institute of America, Inc. |
| Archivo | Labels and controls | Variable, 600–800 | https://github.com/Omnibus-Type/Archivo |

Load `fonts.css` from a local stylesheet link. Font loading uses `font-display: swap` and does not call an external font service. Keep these font notices with any redistributed copy; the repository's software license does not replace the font licenses.
