# Seguridad

No publicar credenciales, datos de clientes, documentos internos, trazas reales, estados Terraform ni inventarios de una cuenta. Los ejemplos deben utilizar datos sintéticos y valores de configuración evidentes.

Para reportar una vulnerabilidad, utilizar la pestaña Security de GitHub y el canal privado de reporte cuando esté disponible. Si no aparece, abrir una incidencia que solicite un canal privado, sin incluir detalles explotables ni información sensible.

La demo ejecuta controles dentro del navegador con finalidad educativa. Un usuario puede modificar su estado local. En una implementación real, autorización, idempotencia, auditoría y políticas deben imponerse en servicios confiables del backend.
